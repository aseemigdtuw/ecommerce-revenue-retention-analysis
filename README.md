## Business problem
An online retailer wants to understand what drives revenue, which product categories create return-related losses, which acquisition channels bring higher-value orders, and how effectively it converts customers into repeat buyers.

## Dataset
This project includes two **synthetic, generated datasets**:
- `data/orders.csv` — 3,600 order records with order value, discount, category, channel, payment method, delivery time, support tickets and order status.
- `data/customers.csv` — 900 customer records with segment, city and signup date.

## Tools
Python (pandas, matplotlib), SQL, and optionally Power BI.

## Metric	Result
Valid orders	: 3,460
Net revenue	: ₹93,21,719
Average order value : ₹2,694
Return rate	: 8.9%
Repeat customer rate	: 91.8%
